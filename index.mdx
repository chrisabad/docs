AgentOS is a multi-agent platform built on OpenClaw that runs businesses autonomously. It manages 30 specialized AI agents organized across 7 companies — handling everything from infrastructure maintenance and code review to content creation and financial reporting, all without manual intervention.

## How AgentOS works

Work enters the system through Slack (Juno's interface) or directly via Paperclip issues. Reed, the dispatcher, routes work to the right agent. Agents execute asynchronously, submit for review, and issues close automatically after review passes.
