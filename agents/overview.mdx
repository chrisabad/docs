## Model tiers

Every agent is assigned a model tier. The tier determines which model handles that agent's runs in priority order.

| Tier | Model chain | Agents using it |
|------|-------------|-----------------|
| **pro** | GLM 5.1 → Sonnet → Gemini Pro | Juno, Axel, Quinn, Diag, Comms, Vera |
| **fast** | Gemma4 → Haiku → Flash | Fen |
| **routine** | GLM 5.1 → Haiku | Reed, Ellis, Orion, Sage, Marlowe, Arlo, Cass, Lev, Maren, Nomi, Home, Supervisor, all reviewers |
| **routine-code** | Qwen3-Coder → GLM → Haiku | Willa, Finn |
| **heartbeat** | Ministral 3 8b → Flash | All agents (heartbeat checks only) |

## Wake patterns

Agents activate in one of two ways.

### wakeOnDemand

Most agents use this pattern. They sleep until Paperclip assigns them an issue, then the issue-trigger plugin wakes them via the gateway. No idle compute is used between runs.

### Cron / heartbeat

Some agents have scheduled recurring work:

- **Fen** — 4 WEE routines: meeting watcher, room check, health scan, morning brief
- **Orion** — 25 monitoring crons (migrating from Juno, tracked in AGE-40)
- **Home** — 3 personal crons: messages sync, daily nudge, weekly reflection
- **Supervisor** — Periodic fleet audits

## Agent context files

Each agent has structured context files stored at `~/.openclaw/workspace/agents/<id>/`.

| File | Purpose |
|------|---------|
| `SOUL.md` | Identity, voice, operating principles, behavior rules |
| `HEARTBEAT.md` | What to do on each heartbeat or wake cycle |
| `AGENTS.md` | Collaboration rules, protocols, sub-agent permissions |
| `IDENTITY.md` | Name, role, personality traits |
| `TOOLS.md` | Available tools and how to use them |
| `USER.md` | Context about Chris |
| `DREAMS.md` | Long-term goals and aspirations |

Shared context for all agents lives at `~/.openclaw/workspace/agents/shared/`:

- `BOOTSTRAP.md` — Common bootstrap instructions
- `base-instructions.md` — Shared operating rules, including timeout and budget awareness
- `urgency-triage.md` — How to classify urgency levels
