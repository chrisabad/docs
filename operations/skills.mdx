Skills are structured instruction sets that give agents domain-specific capabilities. Each skill is a `SKILL.md` file containing step-by-step instructions, tool usage patterns, and success criteria. Skills can be shared across agents and are the primary mechanism for extending what an agent can do.

## Skill file format

Each skill is a `SKILL.md` file with the following structure:

- Step-by-step instructions for the agent
- Tool usage patterns
- Success and failure criteria
- Optional `references/` subdirectory for supporting material

## Creating a skill

Use the `skill-creator` skill, which handles the full creation workflow:

<Steps>
  <Step title="Scaffold the SKILL.md structure">
    The `skill-creator` skill generates the standard file layout and section headings.
  </Step>
  <Step title="Add references">
    Add any supporting files to the `references/` subdirectory.
  </Step>
  <Step title="Register the skill in config">
    The skill is added to `openclaw-schema.json` so the gateway knows about it.
  </Step>
  <Step title="Assign to agents">
    The skill is assigned to the relevant agents in their config definitions.
  </Step>
</Steps>

## ClawHub

The `clawhub` skill provides access to a skill registry. You can use it to search for available skills, install skills from the registry, update existing skills, and publish new skills for others to use.
