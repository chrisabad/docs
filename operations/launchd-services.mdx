title: "macOS Launchd Services Running AgentOS"
description: "Every launchd service that keeps AgentOS running — gateways, Paperclip, health daemons, intelligence connectors, and scheduled jobs with plist labels."
---

AgentOS runs entirely on macOS via **launchd**, Apple's service management framework. All plist files live in `~/Library/LaunchAgents/`. Services marked `KeepAlive: true` are automatically restarted by launchd if they crash.

<Warning>
The Mac app is disabled. Always use launchd plists to manage the gateway — never use the OpenClaw Mac app.
</Warning>

## Core services

These services must always be running. All have `KeepAlive: true`.

| Plist label | Port | What it does |
|-------------|------|-------------|
| `ai.openclaw.gateway` | 18790 | **Primary gateway** (AGE company). Runs via `gateway-prestart.sh` → `node dist/index.js gateway`. 6 GB V8 heap. |
| `ai.openclaw.gateway-2` | 18793 | **Secondary gateway** (all other companies). Same codebase, different company scope. |
| `com.paperclipai.server` | 3100 | **Paperclip server**. Issue tracking. Starts via `~/.paperclip/patches/start-paperclip.sh`. |
| `com.openclaw.postgres` | 54329 | **PostgreSQL**. Used by Paperclip and LiteLLM. |
| `com.openclaw-llm-proxy` | 8082 | **Claude OAuth proxy**. Translates OpenAI-format requests to Claude OAuth using the Weekend subscription. |
| `ai.openclaw.litellm-proxy` | 4000 | **LiteLLM proxy** (Docker). Model routing and failover. |
| `ai.openclaw.healthd` | 18792 | **Health daemon**. Monitors 17 subsystems every 30 seconds. |

## Agent health services

| Plist label | Interval | What it does |
|-------------|----------|-------------|
| `ai.openclaw.agent-health-autoheal` | 30s | Resets `error` status agents across all 7 companies. Circuit breaker activates after 3 systemic failures. |
| `ai.openclaw.paperclip-heartbeat-liveness` | 120s | Checks the `heartbeat_runs` table. Files a Paperclip issue if no runs appear in 5 minutes. |
| `ai.openclaw.paperclipai-rss-watchdog` | 120s | Monitors the Paperclip RSS feed for anomalies. |

## Webhook and intelligence connectors

These services route inbound events into the system and push data into Graphiti for long-term memory.

| Plist label | What it does |
|-------------|-------------|
| `ai.openclaw.smart-webhook-proxy` | Routes inbound webhooks to the right gateway |
| `ai.openclaw.figma-webhook-proxy` | Figma-specific webhook routing |
| `ai.openclaw.frameio-webhook-proxy` | Frame.io webhook routing |
| `ai.openclaw.gmail-dispatcher` | Gmail event dispatch |
| `ai.openclaw.gmail-multiwatch` | Multi-account Gmail monitoring |
| `ai.openclaw.intel-calendar` | Calendar → Graphiti (runs at 8:00 and 18:00 daily) |
| `ai.openclaw.intel-email` | Email → Graphiti |
| `ai.openclaw.intel-slack` | Slack → Graphiti (every 30 minutes) |
| `ai.openclaw.intel-granola` | Granola transcripts → Graphiti |

|-------------|----------|-------------|

| `ai.openclaw.log-rotate` | 03:00 daily | Rotates logs larger than 100 MB, keeps 3 copies |

| `ai.openclaw.safety-tag` | Scheduled | Safety tagging |

## Managing services

<Tabs>
  <Tab title="Load / unload">
    ```bash
    # Load a service
    launchctl load ~/Library/LaunchAgents/ai.openclaw.gateway.plist

    # Unload a service
    launchctl unload ~/Library/LaunchAgents/ai.openclaw.gateway.plist
    ```
  </Tab>
  <Tab title="Check status">
    ```bash
    # List all openclaw services and their PIDs
    launchctl list | grep openclaw
    ```
  </Tab>
  <Tab title="View logs">
    ```bash
    # Stream gateway logs
    tail -f ~/.openclaw/logs/gateway.log
    ```
  </Tab>
</Tabs>

<Note>
Any restart that affects the gateway must happen during the 2–4 AM PT maintenance window. See [Maintenance Windows](/operations/maintenance-windows) for the full policy and exception process.
</Note>
