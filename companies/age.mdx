AGE is the **meta-company** — the company responsible for maintaining the AgentOS platform that all other companies depend on. Because platform reliability is critical, AGE runs on its own dedicated Gateway-1 (port 18790) rather than sharing Gateway-2 with the six product companies. Every change to core platform files must be tracked under an open AGE issue before work begins.

## Gateway assignment

AGE uses **Gateway-1 on port 18790** exclusively. This gives infrastructure work dedicated throughput and prevents platform-level operations from competing for capacity with product company workloads on Gateway-2.

## Issue flow

```text
Issue created → Reed triages by domain signal
    ↓
Axel or Ellis picks up (wakeOnDemand)
    ↓
Implementer works → moves to in_review
    ↓
Quinn auto-assigned → reviews
    ↓
PASS → done  |  FAIL → back to implementer
```

## Change protocol

All AGE changes follow the **agentOS-change** skill protocol and are classified by size:

<Tabs>
  <Tab title="Small">
    Direct implementation followed by standard Quinn review. No PRD required.
  </Tab>
  <Tab title="Large">
    A PRD is required before implementation begins. Juno reviews and approves the PRD first.
  </Tab>
  <Tab title="Structural">
    PRD required, plus explicit Chris approval before any work starts. Reserved for changes that affect the architecture of the platform.
  </Tab>
</Tabs>

<Warning>
Every change that touches a covered file — including `SOUL.md`, `AGENTS.md`, and `openclaw-schema.json` — must have an open AGE issue. Do not edit these files without a corresponding issue.
</Warning>
